# **Directional Nonlinear Principal Components: A Measure Transportation Approach**

This project contains code to reproduce the results of the paper with the same name by Hallin, M. Radojicic, U., and Nordhausen, K.

The goal is to introduce a novel directional nonlinear PCA based on optimal transport. The code below is once for dimension 2 and once for dimension 3. 

**Main functions**

All code here is written in R and requires the packages transport, ICtest, SDraw and mvtnorm.

The main functions are:

-   dirNLPCA_2D.R Functions for the 2D setting
-   dirNLPCA_3D.R Functions for the 3D setting
