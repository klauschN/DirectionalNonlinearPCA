Directional nonlinear principal components: interactive figures

Interactive versions of the three-dimensional figures of M. Hallin, K. Nordhausen and U. Radojicic, Directional nonlinear principal components: a measure transportation approach. The figures can be rotated with the mouse and zoomed with the mouse wheel. They were computed with the R package ospca and the script paper_examples.R.

  • Trivariate example: the data with the one-sided (navy) and classical (red) principal directions
  • Trivariate example: directional dimension reduction with k = 1, ..., 6 directions
  • Gvessel data: the first two directional principal curves, compared with PCA, the principal curve, the autoencoder and GS-PCA
